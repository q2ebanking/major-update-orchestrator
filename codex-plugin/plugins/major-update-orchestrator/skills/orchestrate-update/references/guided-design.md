# Guided design

Use this when the architectural choice is not already approved. Ask focused
questions in this order:

1. What outcome and non-negotiable constraints define success?
2. Which package boundaries, consumers, and compatibility commitments matter?
3. What migration, rollout, and rollback paths are realistic?
4. Which alternatives would materially change cost, risk, or timing?

Summarize the choices and recommendation in the Design artifact. Present it for
approval before deriving the work-unit plan. Keep the Design artifact about
architecture and trade-offs; put estimates, states, and sequencing only in the
living plan.
